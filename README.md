# Gym Rats Clone

Clone do aplicativo **Gym Rats** com **React Native + TypeScript**, contendo **Login** e **Home**, utilizando **componentes nativos** e navegação com **Stack Navigator** e **Bottom Tabs**.

## Páginas

**Login**  
- Campos de email e senha  

**Home**  
- Exibição de informações de treino que imitam o original

## Navegação

- **Stack Navigator:** Login → Home  
- **Bottom Tabs:** seções dentro da Home (ex.: Perfil, Treinos, Configurações)  

## Tecnologias

- React Native (componentes nativos: `View`, `Text`, `TextInput`, `Button`, etc.)  
- React Navigation (Stack Navigator e Bottom Tabs)  
- TypeScript / `.tsx`  
- Expo  
- Bibliotecas para ícones e fontes personalizadas  

## 🛠️ Como rodar

```bash
git clone https://github.com/isabellammachado/gym-rats.git
cd gym-rats
npm install
npx expo start
